# Data description

The original data used in this study were obtained from the Human Connectome Project (HCP):

https://www.humanconnectome.org/

Due to HCP data use restrictions, the full dataset cannot be redistributed in this repository.

The main analysis requires an input file:

GSR-CDM.xlsx

The file should contain:

- Column 1: Subject ID
- Columns 2–8: NACI values for seven task paradigms

Additional columns may include robustness-analysis results and cluster labels.
